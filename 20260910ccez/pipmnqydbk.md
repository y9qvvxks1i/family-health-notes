# 什么是试管婴儿(试管婴儿大揭秘)

> 更新时间：2026-09-10 (UTC+8)

**什么是试管婴儿？**

很多人谈试管婴儿色变，因为他们以为“试管婴儿”是在试管里长大的婴儿。其实，试管婴儿技术是体外受精一胚胎移植技术（IVF-ET）的俗称，是分别将卵子和取出后，置于培养液内使卵子和受精，发育成胚胎后，再将胚胎移植回母体发育成胎儿。

**什么情况下需要做试管婴儿？**

有以下情况人群可做试管婴儿:a.女性盆腔或输卵管异常；b.存在明显内膜异位症或者排卵障碍的患者，经过正规、反复的促排卵治疗后仍不孕；c.病因不明的不孕患者，通过人工授精后仍不孕；d.男性存在重度少精、弱精、畸精，甚至没有。

**如何做试管婴儿？**

试管婴儿进行的步骤如下:

a.选择符合适应症的夫妇，

b.完善术前检查

c.进行促排卵→取卵 → 取精 → 体外受精、胚胎体外培养 → 胚胎移植 → 黄体支持14天→ 验孕。

**试管婴儿技术有几种？**

试管婴儿按照技术的适应症不同，分为三种:一代，二代，三代。是否代数越高、级别越高、率越高呢?其实不然，叫第几代只是便于区分，不同代数的技术适应情况不同。

第一代试管婴儿，就是常规体外受精(IVF)，是指分别将卵子和取出后，置于培养液内使其自行结合(犹如“自由恋爱”)，发育成胚胎后移植入宫腔内。第一代试管婴儿技术主要是针对女性不孕的辅助育技术，适应于以下情况:输卵管性不孕、排卵障碍、内膜异位症和腺肌症、不明原因不孕等。

**第一代试管**

第二代试管婴儿，就是卵胞浆内单纤维注射(ICSI)，是使用显微操作技术将注射到卵细胞胞质内，使卵子受精，体外培养到早期胚胎，再放回母体内发育着床。第二代试管婴儿技术主要是针对男性不育的辅助育技术。适应于以下情况:梗阻性无精症、精功能障碍、无顶体或功能异常、严重少、弱、畸形等

**第二代试管**

第三代试管婴儿，就是胚胎植入前遗传学检测(PGT)，是指在体外受精过程中，对具有遗传风险的胚胎进行植入前活检和遗传学分析，以选择无遗传学疾病的胚胎植入宫腔，从而获得正常胎儿的技术方法。分为胚胎植入前遗传学诊断(PGD)和植入前遗传学筛查(PGS)。第三代试管婴儿，技术主要是针对优优育的辅助育技术，适应于以下情况:常染色体显性遗传病、常染色体隐性遗传病、性连锁隐性遗传病、反复种植失败等。

**试管婴儿的率是多少？**

按女方不同年龄段算，30岁妊娠率约为50%，30岁-39岁妊娠率约为40%，40岁以上妊娠率约为20%。

**影响试管婴儿率的主要因素有哪些？**

a、年龄:是影响试管婴儿率中最重要的因素之一，因为随着年龄增加，女性卵巢功能会逐渐减退，卵子质量下降，男性的质量也会有明显下降。因此进行试管婴儿的最佳年龄应不超过35岁。

b、环境:在胚胎移植到之后，如果环境不佳，例如存在内膜炎、内膜息肉等病变，会改变环境，导致内膜容受性差，容易影响胚胎发育，从而导致试管婴儿失败。

c、胚胎质量:如果选择的或者卵子存在先天性异常，如染色体数目异常或染色体结构缺失，都会极大影响胚胎的存活率。
